# Linguagem ubíqua

| Termo | Significado |
|---|---|
| Sessão de captura | Execução identificada; pode incluir cidade, espera, hunt e refill |
| Hunt | Caça reconhecida dentro da sessão |
| Trecho | Intervalo classificado por atividade |
| Volta fechada | Intervalo encerrado pelo critério daquela hunt |
| Volta limpa | Volta não parcial, com duração positiva e inferior a 360 s |
| Leitura | Valor observado com origem, instante e qualidade |
| Lacuna | Valor ausente ou inválido; nunca zero inventado |
| Total observado | Soma do que foi lido; pode conter lacunas |
| Taxa | Numerador e duração das mesmas voltas com medida válida |
| Raw estabilizada | Mediana superior das raw consolidadas das voltas limpas |
| Supplies pessoais / da party | Medidas distintas, com denominadores próprios |
| Snapshot observado | Estado visível no editor; não comprova aplicação |
| Confirmação | Registro versionado do usuário associado à sugestão |
| Aplicação comprovada | Evidência específica de configuração aplicada no jogo |
| Fase | Intervalo de validade da configuração; não reescreve eventos passados |
| Modelo validado | Aceito em período cronológico posterior ao treino |
| Episódio de KS | Golpes observados de não aliados, com fronteiras e provas |
| Escudo desconhecido | Evidência insuficiente; não equivale a escudo caído |
| Box | Agrupamento espacial de combate; interpretação depende da vocação |
| Coordenada local / de mundo | Referenciais diferentes; transformação explícita |

Raw, supplies, refill, box e RTC continuam sendo os termos familiares da interface. Os contratos carregam as distinções sem adicionar linguagem técnica ao fluxo do jogador.
